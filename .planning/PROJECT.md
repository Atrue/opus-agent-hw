# Backprop Trainer — Интерактивный тренажёр обучения нейросетей

## What This Is

Бесплатный браузерный тренажёр, в котором студент **сам пошагово исполняет** forward- и backward-pass готовой нейросети (MLP: XOR → спираль → MNIST) и видит каждую операцию: входы, выходы, активации, градиенты — от диаграммы архитектуры до drill-down любого отдельного числа. Аудитория — студенты первых курсов DL (P1) и преподаватели ML (P2); для самоучек-свитчеров (P3) ценность в v1 частичная. Позиционирование: «backprop без магии — на числах, в браузере, за один клик».

## Core Value

Пользователь сам исполняет каждый шаг forward/backward-pass готового сценария и видит каждый градиент числом (DOCS-01) — при нулевом пороге входа: браузер, без регистрации, ссылка = продукт (DOCS-04). Всё остальное подчинено этому; North Star — число пользователей в неделю, завершивших полный walkthrough хотя бы одного сценария.

## Business Context

- **Customer**: студенты 1-го курса DL (CS/DS) — P1; преподаватели/семинаристы ML — P2 (узловая роль B2B2C: канал + удержание + будущий B2B-покупатель)
- **Revenue model**: R1 — бесплатно полностью; монетизация — value-based tiered B2B (вузы/буткемпы) как опцион за гейтом после R2-метрик (D-08, D-13); студенты и контент — бесплатно навсегда (D-12)
- **Success metric**: Weekly completions — пользователи/неделю, завершившие полный walkthrough (forward + backward) ≥ 1 сценария

## Context

- **Стадия: идея, до кода.** Стратегический пакет готов (docs/01–05 + PRODUCT.md, DECISIONS.md, STATE.md, EVIDENCE.md в корне). Продукта, лендинга, интервью и измерений нет; все рыночные утверждения — гипотезы H1–H6.
- **Самое рискованное допущение**: H2 (преподаватели готовы встроить тренажёр в курс) + H1 (пошаговость даёт прирост понимания > 20% в A/B). На H2 держатся 4 блока бизнес-модели. H2/H3 проверяются ДО написания кода (D-18): 5 проблем-интервью с преподавателями + юзабилити-тест на кликабельном макете walkthrough XOR.
- **MVP R1** = DOCS-01 + DOCS-02 на сценарии XOR (D-18): один сценарий XOR на MLP до полного walkthrough.
- **Конкурентное поле**: TF Playground (результат без процесса), 3Blue1Brown (пассивно), numpy-ноутбук (высокий порог), PyTorch `.backward()` (магия). Мы — единственная точка, где пошаговость backward + каждое число + визуализация графа + нулевой порог совмещены. LLM-ассистенты — соседний JTBD («бот — учебник, тренажёр — спортзал», D-06).
- **Рост**: PLG, ссылка = продукт; B2B2C через преподавателей → SEO/интерактивные статьи → сообщества. RU-рынок как плацдарм, потом EN (D-10).

## Constraints

- **Tech stack**: Всё в браузере (JS/WASM), статик-хостинг, серверных вычислений нет — архитектура нулевой себестоимости (NFR-03, D-03/D-05)
- **Performance**: Один шаг любого сценария, включая MNIST, < 100 мс на среднем ноутбуке без GPU (NFR-01)
- **Correctness**: 100% операций покрыты автотестами против эталонной реализации (reverse-mode autodiff; референс micrograd/PyTorch на тех же весах); относительное отклонение ≤ 1e-6 (NFR-02) — опечатка в градиенте убивает доверие к продукту
- **Privacy**: Аналитика анонимная, готовый инструмент (Buy); без регистрации (100% сессий); 152-ФЗ/GDPR-совместимость (D-16)
- **Resources**: Один автор; переменные издержки на пользователя ≈ 0 — условие устойчивости (D-08)
