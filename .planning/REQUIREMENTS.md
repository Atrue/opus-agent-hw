# Requirements: Backprop Trainer — Интерактивный тренажёр обучения нейросетей

**Defined:** 2026-11-02
**Core Value:** Пользователь сам пошагово исполняет forward/backward-pass готового сценария и видит каждый градиент числом — в браузере, без регистрации, по одной ссылке.

> Источник: корневой `REQUIREMENTS.md` (спецификация v1, R1) — полные acceptance criteria (Given/When/Then) живут там и являются каноническими. Этот файл — GSD-трекуемая версия тех же требований + table stakes из `.planning/research/FEATURES.md`.

## v1 Requirements

Requirements for initial release (R1). Each maps to roadmap phases.

### Walkthrough Execution

- [ ] **DOCS-01**: Пользователь сам исполняет каждый шаг forward- и backward-pass готового сценария и видит входы, выходы, активации и градиенты операции конкретными числами; индикатор маршрута показывает «шаг N из M»; последний шаг корректно завершает walkthrough (сводка + следующий сценарий), без NaN/пустых состояний
- [ ] **UX-01**: Пользователь может шагнуть назад (переиграть предыдущий шаг) — следствие deterministic-replay архитектуры; ожидаемо аудиторией подобных тренажёров (table stakes из исследования)

### Drill-down Visualization

- [ ] **DOCS-02**: С любого уровня визуализации можно углубиться до отдельного числа: диаграмма архитектуры → слой (список операций) → операция (входы/выходы) → число (формула + источник); на границе графа (первый слой) панель показывает входные данные / старт цепного правила, а не пустой экран

### Scenario Library

- [ ] **DOCS-03**: Библиотека сценариев XOR → спираль → MNIST с методическим нарративом; завершённые отмечаются, следующий рекомендуемый подсвечивается; принудительной последовательности нет — любой сценарий полностью доступен с первого визита

### Zero-threshold Access

- [ ] **DOCS-04**: Любой сценарий открывается по прямой ссылке без установки и регистрации; от открытия URL до первого выполненного шага < 1 мин; повторное открытие ссылки восстанавливает прогресс локально (или честно сбрасывает) без требования регистрации

### Lecture Mode

- [ ] **DOCS-05**: Сценарий воспроизводим пошагово на проекторе без подготовки: каждый шаг читаем с дальних рядов, маршрут детерминирован при повторении; после обрыва сети шаги продолжаются (все вычисления на клиенте), перезагрузка по той же ссылке возвращает то же состояние маршрута
- [ ] **UX-02**: Клавиатурная навигация по шагам (стрелки / презентерный пульт) — table stakes для лекционного режима из исследования

### Understanding Measurement

- [ ] **DOCS-06**: Пропускаемый pre-тест (5 вопросов) и post-тест из тех же вопросов; индивидуальный прирост пишется в анонимную агрегированную аналитику; пропуск pre-теста не гейтит доступ, post-тест всё равно предлагается, данные помечаются «без базовой линии»

### Platform Table Stakes

- [ ] **UX-03**: Базовая мобильная читаемость (адаптив, числа не выпадают) — аудитория заходит «с ноутбука или телефона» (docs/02)
- [ ] **UX-04**: Базовая доступность: клавиатурный фокус на интерактивных элементах, контраст, ARIA-метки на числах/шагах

## Non-Functional Requirements (Definition of Done guardrails)

- **NFR-01**: Один шаг любого сценария, включая MNIST, — < 100 мс на среднем ноутбуке без GPU
- **NFR-02**: 100% операций каждого сценария покрыты автотестами против эталонной реализации (reverse-mode autodiff, референс — micrograd/PyTorch float64 на тех же весах); относительное отклонение ≤ 1e-6
- **NFR-03**: Статик-хостинг; все вычисления в браузере (JS/WASM); серверных вычислений нет; переменные издержки ≈ 0; 100% сессий без регистрации; аналитика анонимная (готовый инструмент, Buy)

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Свободный конструктор сетей + загрузка CSV в v1 | Порог входа и время до «ага-момента» решают всё; → R2 (D-02) |
| Модели крупнее MNIST; оптимизация производительности в ущерб наглядности | MNIST — потолок v1 (D-03) |
| Десктоп / облако / GPU | Никогда в v1 (D-03, D-05) |
| Все архитектуры, RL, трансформеры | Не наш сегмент — глубина вместо широты (D-04) |
| Монетизация на старте, B2C-подписка | Гейт после R2-метрик (D-08, D-13) |
| Реклама, продажа данных | Закрытые двери — доверие образовательного продукта, 152-ФЗ/GDPR (D-16) |
| Регистрация / аккаунты | 100% сессий без регистрации — by design (D-05) |
| Аудитории: исследователи/аспиранты, продакшн ML-инженеры, kaggle, «курс по ML целиком» | Не обслуживаем (docs/01 п.2) |

## Definition of Done

- Все v1 requirements реализованы, проверены (автотесты + ручная проверка acceptance criteria из корневого `REQUIREMENTS.md`) и закоммичены
- NFR-01..03 подтверждены: перф-проверка шага, зелёные golden-фикстурные тесты всех сценариев, статик-деплой без серверных вычислений
- Анонимная аналитика событий (шаги, завершения, pre/post) работает на проде
