# Roadmap: Backprop Trainer — Интерактивный тренажёр обучения нейросетей

## Overview

Путь от идеи до R1: сначала дёшево проверить самые рискованные допущения (D-18 — 5 проблем-интервью с преподавателями на H2 и юзабилити-тест кликабельного прототипа XOR на H3, до какого бы то ни было кода), затем построить собственный тензорный движок float64 (PyTorch-имена, юнит-эталоны — NFR-02) и на нём MVP — полный walkthrough XOR с числами и drill-down до формулы (MVP R1 по D-18), затем расширить до библиотеки сценариев XOR → спираль → MNIST с нулевым порогом входа и лекционным режимом, и наконец включить замер прироста понимания (валидация H1) с анонимной аналитикой, доступностью и подготовкой к пилотам. Каждая фаза завершается проверяемой способностью продукта.

> Ревизия 2026-11-02 (архитектурное ревью фазы 01, `.planning/reviews/01/DECISIONS.md`): forward-only UX (эпохи, fast-forward, сброс; «назад» исключён), тензорный движок вместо Python-конвейера golden-фикстур, reload = честный сброс. Между фазами 1 и 2 вставляется под-фаза 1.1 «Архитектурный рефакторинг R1–R5».

### Phase 2: Движок и MVP-walkthrough на XOR
**Goal**: Пользователь сам проходит полный walkthrough XOR-сценария на MLP — исполняет каждый шаг forward/backward-pass, видит каждое число и Drill-down до формулы — на движке, чья корректность доказана тестами (MVP R1 по D-18)
**Mode:** mvp
**Depends on**: Phase 1
**Requirements**: DOCS-01, DOCS-02, UX-02
**Success Criteria** (what must be TRUE):
  1. Пользователь сам исполняет каждый шаг forward- и backward-pass XOR и видит входы, выходы, активации и градиенты операции конкретными числами; индикатор показывает «эпоха N · шаг M» и фазу прохода; экран завершения эпохи (L до/после, точность) продолжается следующей эпохой, NaN и пустых состояний нет
  2. С любого уровня визуализации можно углубиться до отдельного числа: диаграмма архитектуры → слой → операция → число (формула + источник); на границе графа панель показывает входные данные / старт цепного правила, а не пустой экран
  3. Клавиатурная навигация: `→` / `Space` — шаг вперёд («назад» исключён ревью R3); fast-forward «Запустить эпоху» даёт числа, идентичные пошаговому исполнению
  4. 100% операций движка покрыты юнит-тестами эталонных констант (отклонение ≤ 1e-6) и инвариантами «drill-down = движок», «пошагово = fast-forward»; шаг < 100 мс — NFR-01/02 выполнены структурно, а не обещанием

### Phase 3: Прогрессия сценариев и лекционный режим
**Goal**: Любой сценарий прогрессии XOR → спираль → MNIST открывается по прямой ссылке без регистрации за < 1 мин до первого шага и воспроизводим на проекторе пошагово, детерминированно, с переживанием перезагрузки
**Mode:** mvp
**Depends on**: Phase 2
**Requirements**: DOCS-03, DOCS-04, DOCS-05, UX-03
**Success Criteria** (what must be TRUE):
  1. Библиотека сценариев XOR → спираль → MNIST с методическим нарративом: завершённые отмечаются, рекомендуемый следующий подсвечивается, принудительной последовательности нет — любой сценарий полностью доступен с первого визита
  2. Любой сценарий открывается по прямой ссылке без установки и регистрации; от открытия URL до первого выполненного шага < 1 мин; повторное открытие ссылки честно сбрасывает прогон (URL несёт только сценарий; старт детерминирован фиксированными весами) без требования регистрации
  3. Сценарий воспроизводим на проекторе без подготовки: каждый шаг читаем с дальних рядов, повторение детерминировано; перезагрузка по той же ссылке честно сбрасывает к тому же детерминированному старту; после обрыва сети шаги продолжаются (все вычисления на клиенте)
  4. На мобильном базовая читаемость: адаптивная вёрстка, числа не выпадают
  5. Шаг MNIST < 100 мс на среднем ноутбуке без GPU; спираль и MNIST автоматически проходят тот же CI юнит-эталонов и инвариантов — NFR-01/02 держатся на масштабе без переговоров

### Phase 4: Замер понимания и подготовка к пилоту
**Goal**: Прирост понимания измерим (инструмент валидации H1): пропускаемый pre/post-тест пишет прирост в анонимную агрегированную аналитику; продукт доступен, отхарднен и готов к пилотным запускам у преподавателей
**Mode:** mvp
**Depends on**: Phase 3
**Requirements**: DOCS-06, UX-04
**Success Criteria** (what must be TRUE):
  1. Пользователь может пропустить pre-тест (5 вопросов) и всё равно получить post-тест из тех же вопросов; пропуск не гейтит доступ, данные помечаются «без базовой линии»
  2. Индивидуальный прирост понимания попадает в анонимную агрегированную аналитику; North Star (пользователи/неделю, завершившие полный walkthrough) и события воронки наблюдаемы на дашборде
  3. Базовая доступность соблюдена: клавиатурный фокус на интерактивных элементах, контраст, ARIA-метки на числах и шагах
  4. Прод готов к пилоту: статик-деплой без серверных вычислений, анонимная аналитика работает на проде, офлайн после загрузки не ломает продукт (чистая консоль при заблокированной сети)
