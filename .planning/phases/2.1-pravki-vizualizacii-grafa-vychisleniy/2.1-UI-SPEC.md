## Spacing Scale

Без изменений (DESIGN.md §3). Новые константы графа — кратные 4:

| Token | Value | Usage |
|-------|-------|-------|
| NODE_W = NODE_H | 48×48 (квадрат 1:1) | Узлы-значения (фикс 5) |
| CAPACITY_CHARS | 8 | Порог влезания formatKey-строки в блок |
| FRAME_PAD | 12 | Отступ рамки-нейрона от содержимого |
| FRAME_GAP | 4 | Зазор между рамкой и заголовком |

Exceptions: none

## Typography

Без изменений (DESIGN.md §5). Внутри квадратного блока: метка узла сверху (ui-label 10.5px),
значение по центру (.num 12px); при переполнении значение — над блоком (.num, тот же размер).

---

## Color

Без изменений (DESIGN.md §2 — Okabe-Ito роли). Акценты фиксов:

| Role | Value | Usage |
|------|-------|-------|
| Рамка-нейрон | `--color-outline-variant` + фон `color-mix(surface, 6%)` | Полупрозрачный контейнер (фикс 4) |
| Заголовок рамки | `--color-on-surface-variant` | «Нейрон 1» |
| Коллапс-блок | рамка параметра `--color-pos` либо outline-variant + метка n₁ | Квадратный блок-нейрон |
| Тултип | `--color-surface-container-high` (num-hint / g-tip — существующие) | Фикс 2 — только z-order |

Accent reserved for: активная операция (амбер), выбранное звено (primary) — не меняются.

| Update-узел | — (удаляется с графа; формула SGD живёт в панели операции/звене W/drill — копия без изменений) |

## UI Considerations

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| overflow | значение в квадратном блоке | ✅ covered | детерминированный порог CAPACITY_CHARS: длиннее — значение над блоком, блок не растягивается (юнит-гейт) |
| empty | узел до исполнения операции | ✅ covered | «н/д» — существующий контракт сохраняется |
| empty | выход коллапс-блока до forward | ✅ covered | «н/д» в коллапс-блоке — тот же живой гейт |
| interaction | двойной клик (мышь) + клавиатура | ✅ covered | заголовок рамки — button (Enter/Space = коллапс); dblclick по рамке |
| reduced-motion | коллапс/раскрытие | ✅ covered | мгновенно, transition нет (анимации — фаза 4) |
| long-text | подписи параметров (W1[0,1]) | ✅ covered | SvgSubLabel-сабскрипты сохраняются; ширина блока фикс |
