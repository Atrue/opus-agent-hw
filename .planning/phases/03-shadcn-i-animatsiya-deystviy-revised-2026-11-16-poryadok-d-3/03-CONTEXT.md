## Implementation Decisions

### Объём подключения shadcn

- **D-38: Агрессивная замена.** Все пересобираемые на shadcn компоненты пересобираются в фазе 3: кнопки StepControls (primary/quiet), карточки, вкладки/сегмент-контролы, тултипы (radix через shadcn), `kbd`, обёртки степпера, range-слайдер — по составу, который уточнит ресёрч/план. Обязательства: экраны визуально идентичны (DESIGN.md — канон; **ревизия D-49: читается как «стилистика сохранена» — pixel-perfect не требуется**), testid/RU-строки/e2e-селекторы (17 проверок) не меняются, двойной прогон бит-идентичен. Спец-компоненты продукта (граф, формула-строка, лента, панели чисел, drill-down) НЕ мигрируют — shadcn их не заменяет. — **Reversibility:** costly — откат затрагивает все точки использования примитивов в 10 домен-папках `src/ui/*`; сама замена не ломает публичный контракт экрана (testid/строки), поэтому риски локализованы e2e-базлайном.
- **D-49 (ревизия D-38, владелец — план-ревью 2026-11-19): критерий приёмки миграции — сохранение стилистики, не pixel-perfect.** Попиксельное совпадение вычисленных стилей и идентичность внутренней DOM-структуры примитивов НЕ требуются; допустима замена концептуальных UI-блоков на функционально равносильные компоненты кита/библиотек (в рамках состава D-38/D-42). Гейт приёмки: (а) стилистика DESIGN.md сохранена — палитра-токены, типографика (Space Grotesk/Geist/JetBrains Mono), плотность и мелкие радиусы, семантика цветов (мята/циан/амбер), Material Symbols; (б) машинные контракты экрана живы — testid/RU-строки/aria и 17 e2e-проверок без правок, двойной прогон бит-идентичен; (в) скрин-ревью владельцем оценивает целостность «приборной» темы, а не отсутствие отличий. Токен-мост D-39 остаётся точным (алиасы — механика одного источника правды, не визуальный гейт). — **Reversibility:** reversible — критерий приёмки.
- **D-39: Токен-мост алиасами.** CSS-переменные shadcn (`--background`, `--primary`, `--radius`…) объявляются алиасами на существующие `@theme`-токены DESIGN.md в `src/index.css` — один источник правды; правка палитры DESIGN.md распространяется на кит автоматически. Дублирования палитры в shadcn-формате нет. — **Reversibility:** reversible — один CSS-блок.
- **D-40: @floating-ui/react уходит, если radix покроет контракт NumberHint.** Ресэрч/пилот проверяет: портал, z-index поверх SVG-графа (D-35 фикс 2), hover/focus, позиционирование у краёв. Покрывает — зависимость удаляется (минус одна); не покрывает — остаётся только для NumberHint, radix-тултипы живут в ките. Решение фиксируется в RESEARCH.md с доказательством (пилотный компонент до массовой замены). — **Reversibility:** reversible — обе стороны решения дёшевы.

### Пакеты sanctioned-чекпойнта

- **D-41: Material Symbols — единственная иконная система.** `lucide-react` НЕ ставится; при добавлении shadcn-компонентов их lucide-импорты вычищаются, иконки заменяются глифами Material Symbols (пакет `@fontsource/material-symbols-outlined` уже в зависимостях; DESIGN.md Don'ts: «иконки только Material Symbols»). — **Reversibility:** reversible.
- **D-42: Состав пакетов — ядро + radix per-component, один апрув.** Ядро: `class-variance-authority`, `clsx`, `tailwind-merge`, `tw-animate-css` (enter/exit-анимации shadcn; reduced-motion совместимость проверяется ресёрчем). Radix-примитивы (`@radix-ui/react-tooltip`, `-tabs`, `-dialog`, `-select`, `-slider`… по составу замены) — ровно под выбранные компоненты, без веера «на будущее». Итоговый список с версиями/весами/владельцами ресэрч приносит в первый план фазы — один пакетный апрув владельца перед установкой (AGENTS.md №2). Удаление `@floating-ui/react` — по вердикту D-40. — **Reversibility:** reversible — зависимости добавляются/удаляются точечно, e2e держит поведение.

### Размещение и гранулометрия кита

- **D-43: Кит в `src/ui/kit/`.** Внутри ui-дерева: баррел `index.ts` + README; structure-gate R2 доволен (корень `ui` — только README); `components.json` указывает CLI класть компоненты сюда; домены импортируют из `ui/kit` как из библиотеки. Термин `kit` — в глоссарий PROJECT.md (UI-кит проекта на shadcn, вендорная зона). — **Reversibility:** reversible — перемещение папки + правка импортов.
- **D-44: Кит = вендорная зона гранулометрии.** Канонические shadcn-файлы (мультиэкспорт `Button` + `buttonVariants`, cva-варианты) легальны внутри `kit/` — фиксируется README кита и пометкой на ревью планов фазы. Гейт `src/structure.test.ts` НЕ меняется (R1 no-export-default совместим — shadcn использует именованные экспорты; R2 требует подпапку — соблюдено; R4 не про ui). Гранулометрия D-34 (1 субъект/файл) остаётся мягкой инструкцией для доменов; выгода — CLI-обновления компонентов shadcn остаются применимыми (diff-merge против канонических файлов). — **Reversibility:** reversible — документированное исключение, не машинный гейт.

### Рамки анимационного решения

- **D-45: Ресэрч GSAP vs motion vs CSS-only; Spline — краткий отказ.** Spline закрывается в RESEARCH.md кратким обоснованием (3D-редактор с proprietary-рантаймом и онлайн-механикой; конфликт с Don'ts «3D-блобы/параллакс» и «приборной» атмосферой DESIGN.md) — без пилота. Полное сравнение: вес в бандле, лицензии (GSAP-лицензию верифицировать отдельно после перехода Webflow на «всё бесплатно»), интеграция с React 19, влияние на NFR-01 и e2e-детерминизм. Итог — журнализированное решение владельца (частичная супрессия D-23, новая запись DECISIONS.md; ROADMAP критерий 2): один вариант принят или отказ с обоснованием.
- **D-46: Без заранее зафиксированного весового бюджета.** Жёсткий потолок KB gz НЕ фиксируется; вес и лицензия оцениваются качественно в ресэрче (DOCS-04 < 300 KB gz общий ориентир бандла — учитывать как контекст, не как гейт), решение принимает владелец по итогам ресёрча.
- **D-47: Все три точки применения обязательны.** Подсветка активного шага, коллапс/раскрытие нейрона (мгновенный коллапс из 2.1 получает анимацию), поток forward/backward — все три включаются в план; финальный состав/детали — на ревью планов по итогам ресёрча.
- **D-48: Сдержанный функциональный градус.** Микровзаимодействия 150–400 мс, продолжение DESIGN.md §8 «движение = смысл»: подсветка приезжает, коллапс схлопывается плавно, волна по рёбрам читает направление backprop. Без декоративных циклов вне активного действия. reduced-motion: полное отключение несущих анимаций, остаются цветовые переходы ≤ 150 мс; print/lecture-гейты сохраняются. — **Reversibility:** reversible.

### Claude's Discretion

- Точный перечень мигрируемых примитивов внутри «агрессивной замены» (какие из существующих компонентов пересобираются на кит, а какие остаются локальными обёртками) — ресёрч предлагает, ревью планов утверждает.
- Механика токен-моста (какие именно shadcn-переменные нужны выбранному набору компонентов; `@theme inline` vs обычные алиасы в Tailwind 4) — исследовательская деталь.
- Порядок пилотирования radix-тултипа против NumberHint (до массовой замены) — план определяет.
