## Top 3 Priority Fixes

1. **Space на сфокусированном узле/ребре диаграммы исполняет два действия** — `src/ui/StepControls.tsx:19` exempts только `tagName === 'BUTTON'`; SVG hit-элементы (`role="button"`, `tabIndex={0}` в `ArchitectureDiagram.tsx:180/220`) сами обрабатывают Space → `openDrill`, затем global window-listener добавочно зовёт `run.advance()`. Пользователь с клавиатуры открывает drill И одновременно шагает прогон (drill мгновенно автосбрасывается сменой операции — выглядит как «сломанный клик»). Fix: расширить exemption до `event.target.closest('button, [role="button"]')` либо `stopPropagation()` в SVG `onKeyDown`.
2. **`<title>` документа устарел против Rev 1.1** — `index.html:7`: «XOR — backprop за 14 шагов», тогда как контракт (Rev 1.1 «Прочее») и h1 (`App.tsx:66`) — «XOR — backprop по шагам». Вкладка браузера/печать/скринридер-анонс страницы несут отменённую фикцию «14 шагов» при бесконечных эпохах (R3). Fix: заменить на «XOR — backprop по шагам».
3. **`svg[role="img"]` с интерактивными потомками (a11y)** — `ArchitectureDiagram.tsx:277`: корневой svg имеет `role="img"` + aria-label, но внутри 10 интерактивных hit-элементов `role="button" tabIndex={0}`; по ARIA `img` не должен содержать интерактивных потомков — скринридеры могут не объявлять кнопки drill-down. Fix: `role="group"` (или `<figure>`) с тем же aria-label; `LossChart.tsx:43` корректен — он без интерактивных детей.

## Detailed Findings

### Pillar 1: Copywriting (3/4)

Соответствие контракту (проверено строка-в-строку):

- Контролы ровно по Rev 1.1: `[Сброс]` (`btn-reset`), `[Шаг →]` (`btn-next`), `[Запустить эпоху ⏩]` (`btn-epoch`), `«Следующая эпоха»` (`btn-epoch-next`) — `StepControls.tsx:36-75`; «назад»/«к началу» отсутствуют и кнопкой, и клавиатурой (grep ArrowLeft/btn-prev — 0).
- Индикатор `«Эпоха N · пример K · шаг M»` + бейдж фазы (forward/loss/backward/update) в стабильном слоте, `min-width: 124px` бейджа гасит layout shift (`App.tsx:68-78`, `index.css:87`).
- Заголовок экрана `«XOR — backprog по шагам»`… — точно «XOR — backprop по шагам» (`App.tsx:66`) ✓; drill-заголовок `sym — value` (`NumberDrilldown.tsx:24-27`) ✓; backlink `«← к шагу»` ✓; терминальная панель ∂L/∂x — дословно по контракту (`NumberDrilldown.tsx19, 33-53`); глоссарий ∂L/∂W — дословно (`:20`); `«Лекционный режим»` toggle c `aria-pressed` ✓.
- Empty-states авторизованы: вводная панель до первого шага (`OperationPanel.tsx:50-62`), заглушка графика (`LossChart.tsx:49-52`), fallback «Число не найдено…» (`NumberDrilldown.tsx:71`). Невалидный hash молча клампится (`run/url.ts:22-26`, e2e №5).

Найденные дефекты:

- **WARNING** `index.html:7` — `<title>XOR — backprop за 14 шагов</title>`: замороженная Rev 1.0-строка, отменённая Rev 1.1 («без фиксированного „за 14 шагов"»); пользователь видит её во вкладке/истории/печати. Единственное оставшееся «за 14 шагов» в прод-дереве.
- **WARNING** `EpochSummary.tsx:41-43` — «Числа этой эпохи идентичны пошагово и после «Запустить эпоху ⏩»»: QA-инвариант (проверка FF-эквивалентности) утёк в пользовательский копирайт основного экрана; грамматика фразы тоже хромает («идентичны пошагово и после»). Строка не из контрактного словаря — самовольное добавление вне таблицы границ 01.1.
- **MINOR** `hintData.ts:13` — provenance «вес модели (живое значение)» вместо спекового примера «вес, инициализация (seed 42)». Отклонение осознанное (веса теперь живые, R1/R3), но в 01.1-UI-SPEC заявлено «при нулевых правках UI-строк вне словаря» — строку стоило завести в словарь.

### Pillar 2: Visuals (4/4)

- Фокус экрана: активная op — accent-обводка 3px + тинт 10% (`index.css:155-158`, `ArchitectureDiagram.tsx:206-210`), изменившиеся числа — gray-900 на accent-тинте, неизменившиеся — gray-500 (`index.css:140-146`) — метод highlight контракта воспроизведён.
- Анти-«стена цифр» в коде, не на глаз: `operationRows.ts:10-11` — `KEY_NUMBER_CAP = 7`, `PER_TENSOR_CAP = 3`, скрытое — `+N` с drill-down; подписи рёбер `opacity: 0` до active/hover (`index.css:159-172`).
- Иерархия: 3 кегля × 2 веса (см. Pillar 4); иконок нет — Unicode-стрелки по A-7; иконочных кнопок без подписи нет — все текстовые, группы подписаны `aria-label` (`App.tsx:94/100/115`, `StepControls.tsx:37`, `WeightsTable.tsx:42`).
- SVG-диаграмма: слои 2→3→1 слева-направо, цвет ребра = знак (neg/pos), толщина 1.5–4px ∝ |w| с живым пересчётом (`ArchitectureDiagram.tsx:233-247`), hit-мишени 16px + `r+6` с `role="button"` и aria-label «Вес W1[k] = value» (`:179-185`).

### Pillar 3: Color (4/4)

- Источник цветов один — блок `@theme` (`index.css:14-38`): Okabe-Ito neg/pos/attention + AA-варианты `neg-text #C24A00` / `pos-text #007A56` (A-4) + 4 фазных цвета (A-5: тинт 12% + точка + gray-900, `App.tsx:71-78`). Токены дизайна зафиксированы и не перекрашены фазой.
- Accent `#E69F00` — ровно зарезервированные применения: changed-тинт (`index.css:140`), обводка активной op (`:155`, `ArchitectureDiagram.tsx:156`), primary CTA рамка 2px (`index.css:115-118`). Использований в tsx — 4 строки, все из reserved-списка. Поток `.diag-flow` — белый (Dominant-токен), не accent.
- 60/30/10: доминанта white (фон, канва), вторичные `neutral-50`/`neutral-200` (панели, рамки), accent ≤10% — распределение выдержано, в т.ч. в новой зоне истории (те же нейтрали, `App.tsx:119-123`).
- Hardcoded-цвета вне `@theme`: только нейтрали `#FFFFFF/#E5E7EB` в инлайн-стилях неактивного узла (`ArchitectureDiagram.tsx:209`) и в CSS-классах — значения совпадают с контрактными нейтралями; знаковые/фазные — исключительно через `var(--…)`.
- **MINOR (спека, не код)**: UI-SPEC Rev 1.0 внутренне противоречив по тинту changed-числа: L105 «@ 20% alpha» vs L164/L199 «тинт 10%». Реализация — 10% с комментарием (`index.css:140-141`); расхождение с L105 задокументировать или починить спеку.
- **MINOR**: линия лосса — `--color-phase-fwd` (синий forward-фазы) при оранжевых точках эпох (`LossChart.tsx:65,74`): токены-only соблюдено, но семантика «синий = forward» размазана на график лосса; допустимо, отметить для Phase 2.

### Pillar 4: Typography (4/4)

- Ровно 3 кегля default-шкалы через CSS-переменные: `--num-size: 16px`, `--ui-size: 16px`, заголовок `calc(+4px)=20px`, подписи диаграммы `14px × --diag-scale` (`index.css:34-37, 53-74, 159-176`). В tsx нет ни одного Tailwind-кегля `text-xs…text-5xl` (grep — 0) и ни одного стороннего веса (единственный `font-normal` — `WeightsTable.tsx:57` — принудительно возвращает th к весу 400 чисел).
- Ровно 2 веса: 400 (`.num`, `.ui-text`) и 600 (`.ui-label`, `.app-heading`); числа всегда 400 — акцент фоном/цветом (`index.css:53-59`).
- `tabular-nums` на всех числовых поверхностях: `.num`, `.diag-edge-label` (`index.css:58, 161`); JetBrains Mono — числа/формулы, Inter — UI, self-host (`index.css:1-3, 15-16`).
- Лекционный режим: только переменные 16→32 / 16→20 / diag 1.25 / edge ×2 (`index.css:42-47`), 0 JS-пересчёта — контракт «множители тех же ролей» исполнен.
- Формат чисел — единая точка `format/numbers.ts`: `.4g`/`.3e`, display-минус U+2212 с сохранением ASCII после e/E, `formatKey` бросает на NaN/Inf (`numbers.ts:26-30`); индексы — ASCII + `<sub>`-рендер (`SubscriptText.tsx`, план Б §5.5).

### Pillar 5: Spacing (4/4)

Гистограмма классов (tsx): `gap-4/px-6/p-4/gap-2/gap-8/px-2/p-2/gap-1/py-1/py-0.5/pb-6/py-6` — все на шкале xs=4, sm=8, md=16, lg=24, xl=32.

- Контрактные значения воспроизведены точно: page padding `px-6` (24=lg), gap main `gap-8` (32=xl) (`App.tsx:91`), внутренние паддинги панелей `p-4` (16=md), gap строк `gap-2` (8=sm), между числами `gap-x-2`, инлайн-паддинг бейджа `2px 8px` + `gap 4px` (`index.css:82-88`), кнопки `8px 16px` (`index.css:102`).
- Arbitrary-значения — только контрактные размерные, не spacing-декорации: header `h-14` (56px), footer `h-[72px]` (min-height 72), колонки `w-[55%]/w-[45%]`, зона истории `h-[200px]` — высота зоны зафиксирована при планировании 01.1 в порядке Rev 1.1 («зафиксировать при планировании»). `min-height: 40px` кнопок (`index.css:101`).
- Нестандартных отступов, magic-чисел в паддингах/гэпах — не найдено (grep `\[[0-9]*px\]` по tsx — только перечисленные высоты/ширины).

### Pillar 6: Experience Design (3/4)

Сильное покрытие состояний:

- Пустые/edge: вводная панель без чисел до первого шага; empty-state графика; терминальная панель границы графа; fallback неразрешённого ref; невалидный hash → clamp (`url.ts:22-26`, e2e №5).
- Ошибки вычислений исключены до UI: `formatKey`/`exactRepr` бросают на не-конечных (`numbers.ts:27,34`), DOM-скан NaN/Infinity/undefined в e2e №2.
- Loading по контракту N/A (синхронный движок, первый paint полный).
- Клавиатура: → / Space / PgDn → advance, Esc → close drill (`StepControls.tsx:16-34`); фокус-ring 2px `#0072B2` offset 2 глобально, включая SVG (`index.css:122-125, 181-184`).
- Деструктивных подтверждений нет по контракту; «Шаг» никогда не disabled (R3); «Сброс» обратим прогоном.
- A11y-тултипы: `aria-describedby`, Esc/blur, focus-открытие, restMs-задержка (`NumberHint.tsx:36-47`), tap → сразу drill (LOCKED R5); WeightsTable hover-tier без tabIndex — осознанное решение (tab-порядок не загрязнён 13×N ячейками), полный путь — панель/диаграмма.
- Reduced-motion/print гейты глобальные (`index.css:240-252`), `.lecture` поток сохраняет; e2e проверяет computed `animation-name === 'none'` и data-flow forward/backward/нет-на-update.
- URL: reload = честный сброс, hash только `#scenario=xor`, replaceState без истории (e2e №5).

Дефекты:

- **WARNING** Space-конфликт (см. Top fix 1): global-listener (`StepControls.tsx:19-25`) exempts только `BUTTON`; SVG hit-элементы с `role="button"` (`ArchitectureDiagram.tsx:139-144, 180-185, 193-198`) обрабатывают Space сами → двойное действие (openDrill + advance). e2e клавиатурный путь по SVG не покрывает.
- **WARNING** `role="img"` на интерактивном svg (см. Top fix 3) — потенциальная потеря drill-точек для скринридеров.
- **MINOR** Семантика индикатора: «шаг M» = номер СЛЕДУЮЩЕЙ оп (зафиксировано key-decision 01.1-01, e2e №1: после первого клика «шаг 2» при панели с op 1) — панель показывает исполненную операцию, индикатор — предстоящую; в дидактическом контекле воспринимается как off-by-one. Решение задокументировано, но стоит либо проговорить в UI («далее: шаг 2»), либо показывать исполненную.

Registry Safety: `components.json` отсутствует (Tool: none по A-1), сторонних реестров в UI-SPEC нет — раздел неприменим, блок пропущен.
