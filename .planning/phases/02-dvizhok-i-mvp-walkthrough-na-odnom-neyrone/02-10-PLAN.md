Таблиц контрактов и switch-диспетчеров нет: операция сама приносит свой обратный шаг. Аналогия с micrograd-идиомой (проект — учебный micrograd-порт): операция и её градиент рядом.

## Решения ревью владельца (2026-11-13, этот план)

- **Форма операции:** свободная функция `(a: Value, b: Value): Value`; из Value уходят ВСЕ методы (включая backward/runBackward); op-функции — внутренние для src/tensor (index.ts не меняется, внешних потребителей методов нет — проверено ревью).
- **Форма градиента:** внутри op-функции объявлен `backwardFn` (имя владельца), возвращающий чистые локальные производные (без incoming, без мутаций); incoming и аккумулирование — общий код `backward()` (chain rule единообразно, «функция — просто способ расчёта, он у каждой операции разный; всё остальное общее»).
- **Без таблиц/контрактов:** CONTRACTS-таблица, интерфейс ValueOpContract и switch-диспетчер из исходного черновика плана исключены (решение владельца при ревью).
- **Без машинных структурных гейтов:** проверки вида VALUE-DELEGATES/NO-VALUE-SWETCH/VALUE-OPS-CONTRACT убраны; приёмка структуры — ручное ревью владельца (git diff value.ts + value-ops/ на ревью SUMMARY).
- **Числовая цена формы (принята владельцем):** чистые partials меняют ассоциацию для div/log/sigmoid (было fused `incoming / b`, `(incoming·out)·(1−out)`; станет `(1/b)·incoming`, `(out·(1−out))·incoming`) — возможен ulp-дрейф 16-й значащей цифры; для add/sub/neg/mul/tanh перенос бит-идентичен (коммутативность IEEE-умножения точна, `1·x = x`, `−1·x = −x`). Покрытие: toBeCloseTo(15) в мини-тестах, инвариант 1e-12, etalon 1e-6 (путь движка не тронут), e2e (пины — числа движка). Журнализация компромисса — в D-34 (план 02-12).
- **Замыкания в Value-view разрешены:** D-29 «замыкания удалены» ревизуется для Value-слоя (ленивый view drill-down); для движка исполнения (Tensor/BackwardPlan) запрет сохраняется. Фиксация — D-34, план 02-12.
