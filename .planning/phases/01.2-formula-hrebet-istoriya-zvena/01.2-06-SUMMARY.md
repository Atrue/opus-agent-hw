# Plan 01.2-06 SUMMARY: Граф вычислений (gap cycle 2: пункты правил 1–7)

## What Was Built

Диаграмма заменена буквальным вычислительным графом движка (инвариант «граф = drill-down = движок»):

- **compGraph.ts** (чистая модель): инвентарь 43 звеньев — 3 константы (x₁,x₂,y — белая рамка), 13 параметров (W1[j,i]×6, b1×3, W2×3, b2 — зелёная рамка `--color-pos`, обновляются на sgd), 14 узлов-операций (по-элементно: matvec×3, add×3, tanh×3, matvec, add, σ, BCE + ОДНА update-станция «W ← W − η·∂L/∂W»), 13 вычисленных значений (W1x×3, z1×3, a1×3, W2a1, z2, ŷ, L); 64 ребра (45 потоковых + 13 update-пунктиров + 6 x-подводов внутри 45). Детерминированные рамки: координаты = PAD + ранг×PITCH (ранг-колонки топологической глубины 0–16, строки нейронов), VIEW ≈ 1330×438 — чистая функция структуры, юнит-гейты (бит-идентичность двух вызовов, все узлы в рамках, связность ≥1 ребра, инвентарь, группы).
- **ComputationGraph.tsx**: звено-значение — закруглённый квадрат с рамкой роли, значение внутри (`station-value`), градиент под звеном после backward (`node-grad`); звено-операция — круг со значением результата; рёбра операнд→оп→результат с hover-тултипом fwd/bwd (CSS-only `.g-tip`); update-станция (testid update-station, активна амбером на 13-м шаге); подсветки: группа звена цепи primary (.diag-selected, data-selection) + группа активного шага амбер (.active + бегущий пунктир .diag-flow, data-flow корня — классы диаграммных рёбер сохранены, контракты e2e 1/2 живы); клики: параметры/входы/метка → drill, операции → selectLink. Скролл карточки по обеим осям (рамки не сжимаются). Зум 0.5–2.0 (шаг 0.25, кнопки graph-zoom-in/out/reset, transform на внутренней обёртке, лекционный --diag-scale суммируется).
- **chainLinks.ts**: геометрия звеньев = группы графа (SEGMENT_GROUPS; контракт CHAIN_GEOMETRY_IDS = все узлы/рёбра графа); SEGMENTS/symbolToSegment/формулы не изменены (формула-строка без правок).
