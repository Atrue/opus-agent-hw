> D-06 (costly reversibility: перекраска после юзабилити-теста = повторный тест).

(исполнен 2026-11-02), значения ниже — из его вывода.

### 2.4 Принятое исключение: `#E69F00` ниже 3:1 как нетекстовый акцент

Обводка активной op (3px) и рамка CTA «Шаг» (2px) дают 2.25:1 на белом — ниже
порога 1.4.11. Исключение принято осознанно: (а) акцент никогда не единственный
носитель информации — активная op дополнительно видна в формуле/числах StepPanel,
CTA имеет текстовую метку 17.7:1, изменившееся число — тинт + позиция в формуле;
(б) D-06 зафиксировал Okabe-Ito Orange как акцент до юзабилити-теста; (в) та же
палитра проходит 3:1 там, где цвет — единственный различитель знака (рёбра).
Вернуться к решению, если на юзабилити-тесте (01-04) будут жалобы на видимость
подсветки активной op с задних рядов.

## 3. Типографика и кегли

Ровно 2 веса (400/600); числа всегда weight 400 — акцент через фон-тинт и цвет.
`font-variant-numeric: tabular-nums` на всех числах (JetBrains Mono).

| Роль | Шрифт | default | `.lecture` | Вес | Класс |
|---|---|---|---|---|---|
| Числа/формулы | JetBrains Mono Variable | 16px (`--num-size`) | 32px | 400 | `.num` |
| UI-текст, provenance | Inter Variable | 16px (`--ui-size`) | 20px | 400 | `.ui-text` |
| Кнопки, бейджи, индикатор | Inter | 16px (`--ui-size`) | 20px | 600 | `.ui-label` |
| Заголовок сценария (1 на экран) | Inter | 20px (calc +4px) | 24px | 600 | `.app-heading` |
| Подписи диаграммы (SVG) | JetBrains Mono | 14px | 17.5px (×`--diag-scale` 1.25) | 400 | `.diag-node-label`, `.diag-edge-label` |

Диаграмма: толщина рёбер 1.5–4px ∝ |w|, в `.lecture` ×2 (`--edge-scale`); масштаб
подписей `--diag-scale` 1 → 1.25. Оба эффекта — только CSS-переменными, без
JS-пересчёта layout. Отступы: шкала 4/8/16/24/32 (xs–xl), минимальная высота
кликабельных контролов 40px. Focus-ring: 2px `#0072B2`, offset 2px.

## 4. Тинт изменившегося числа — единое значение 10%

Противоречие источников (Color-секция UI-SPEC «@ 20%» против Interaction Contract
и must_haves плана «@ 10%») разрешено планом 01-02 в пользу **10%**:
`color-mix(in srgb, var(--color-attention) 10%, transparent)` на белом ≈ `#fdf5e6`,
контраст gray-900 на нём 16.37:1. Значение зафиксировано здесь как единственное;
`--color-attention` в акцентных ролях (обводка op, рамка CTA) используется без
альфы. 20%-вариант не применяется нигде.

## 5. Нотация (D-06) — одна таблица

| Символ | Значение | Рендер в прототипе |
|---|---|---|
| `x, W, b` | вход, веса, биасы | ASCII |
| `z = W·x + b` | линейный слой | Unicode-строка формулы |
| `a = tanh(z)` | активация скрытого слоя | Unicode-строка |
| `ŷ = σ(z)` | sigmoid-выход | ŷ (U+0177), σ — Unicode |
| `L` | loss (BCE) | ASCII |
| `∂L/∂·` | градиент L по · | **∂ — Unicode (U+2202), рендер системным фолбэком** (см. §7) |
| индексы `z1, W2, b1` | номера слоёв | генератор пишет ASCII; UI рендерит `<sub>`/`<tspan>`-сабскрипт (план Б §5.5: у ₁₂/⊙/←/→ нет глифов в подключённых шрифтах) |
| `·`, `ᵀ`, `−` | умножение, транспонирование, display-минус | Unicode (минус U+2212 — только display; в JSON/экспоненте ASCII `-`) |
| `∂L/∂W` шпаргалка | «градиент L по W (в CS231n: dL/dW)» | глоссарий-строка в NumberDrilldown у любого ∂ (Pitfall 13) |

Одна нотация во всех источниках: генератор (`tools/reference/gen_mock_trace.py`),
UI-хром, документация. Смешение с δ/dL/dW запрещено (Pitfall 13).

**Правило: знак никогда не кодируется только цветом** — явный минус U+2212 в
display всегда сопровождает цвет (Pitfall 6); фаза различается текстовой меткой
бейджа, не только цветом точки.

## 6. Мобильный тир — явное решение (A-6, Pitfall 7)

**Минимальный мобильный режим в прототипе не строится.** Вьюпорт <1024px —
осознанный тир прототипа (юзабилити-тест H3 удалённый на ноутбуках; вертикальная
плотность чисел без адаптации нечитаема). Тир продукта: **numbers-first linear
list** — отложен в Phase 3 вместе с PWA-тиром; решение пересматривается при
планировании Phase 3 по результатам H3 (если респонденты будут пытаться открыть
прототип с телефона — сигнал поднять приоритет).

## 7. Решение по глифам ∂/₁₂/⊙/←/→ (план Б, из 01-02)

Глиф-проверка по `unicode.json` fontsource 5.3.0: в JetBrains Mono Variable и
Inter Variable **нет** U+2081/U+2082 (₁₂), U+2299 (⊙), U+2190/U+2192 (←→); ∂
(U+2202) есть в базовом латинском сабсете Inter, но отсутствует в моно-сабсетах —
в формулах (mono) рендерится системным фолбэком. Решения:
- индексы: генератор → ASCII (`z1`), UI → `<sub>`/SVG `<tspan>` (шрифт не нужен);
- `⊙`→`*`, `←`→`=`, `→`→`->` в данных генератора;
- `∂` оставлен Unicode (D-06 заблокировал замену): фолбэк-шрифт ОС (SF/Segoe/
  Noto) не даёт tofu на десктопах macOS/Windows/Linux; проверка фактического
  рендера — литмус-скриншоты e2e (28 файлов, план 01-03) и наблюдение 01-04;
- «← к шагу» (backlink, Inter) — U+2190 системным фолбэком, принято по тому же
  решению.

Измерение рендера (chromium, 2026-11-02, план 01-03): ∂ в стеке `.num` даёт ширину
15.81px @32px — совпадает с системным моно-глифом и не совпадает с advance
JetBrains Mono (19.20px) и с notdef-боксом (38.41px) → фолбэк задействован и
рендерится реальный глиф, не tofu. Подмножества fontsource (unicodeRange загруженных
faces) U+2202 не содержат — вывод 01-02 подтверждён измерением.

## 8. Лекционный режим — литмус-чекпойнт «с 4–5 м»

`.lecture` на корне: `--num-size` 16→32px (`--ui-size` 16→20, `--diag-scale` 1.25,
`--edge-scale` 2). Порог 32px ≈ «28–32px с задних рядов» (PITFALLS §6).
**Литмус-чекпойнт:** открыть скриншот шага в `.lecture` из `e2e/screenshots/`
(`step-XX.lecture.png`) и оценить читаемость с 4–5 м от ноутбука; формальный
сбор — пост-вопрос юзабилити «видно с задних рядов?» (01-04). Автотесты
проверяют кегли DOM (32px/20px); визуальная оценка — человеческая.

## 9. Потолки чисел (анти-«стена цифр», Pitfall 5)

≤7 ключевых чисел в дефолтном виде шага, ≤30 на всём экране — enforce
юнит-тестами `tests/player.test.ts` на реальном трейсе (14/14 шагов); скрытые до
drill-down значения помечаются «+N». Self-check потолка — скриншоты каждого шага
(`e2e/screenshots/`, 28 файлов) + задание 3 юзабилити («найти число < 10 сек»).
