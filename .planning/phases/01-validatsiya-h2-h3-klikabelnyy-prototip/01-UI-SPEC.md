## Typography

Ровно 3 размера default-шкалы (14/16/20 — чёткая иерархия, разрешение checker-FLAG), ровно 2 веса. Лекционный режим — множожители тех же ролей через CSS-переменные, не отдельная шкала.

| Role | Font | Size (default) | Size (`.lecture`) | Weight | Line Height |
|------|------|---------------|-------------------|--------|-------------|
| Number/Formula — значения, градиенты, формулы (главный контент) | JetBrains Mono, tabular-nums | 16px | 32px | 400 | 1.5 |
| Body/UI — нарратив, подписи, provenance | Inter | 16px | 20px | 400 | 1.5 |
| Label/Controls — кнопки, бейджи, «Шаг N из 14» | Inter | 16px | 20px | 600 | 1.2 |
| Heading — заголовок сценария (1 на экран) | Inter | 20px | 24px | 600 | 1.2 |
| Diagram label — подписи узлов/рёбер SVG | JetBrains Mono | 14px | 28px | 400 | 1.2 |

- Числа всегда weight 400 — акцент через фон-тинт и цвет, не через вес (табличная ровность колонок).
- Реализация: `--num-size: 16px`, `--ui-size: 16px` в `@theme`; класс `.lecture` на корне меняет только переменные + толщину SVG-рёбер ×2 + `--diag-scale: 1.25`. Без JS-пересчёта layout.
- Лекционный порог: 32px числа ≥ «28–32px с задних рядов» (PITFALLS §6).

## Notation & Number Format (D-06)

- Нотация micrograd/CS231n, одна во всех строках (генератор + UI-хром): `x`, `W`, `b`, `z = W·x + b`, `a = tanh(z)`, `ŷ = σ(z₂)`, `L`, `∂L/∂·`.
- Формулы: Unicode-строки из trace JSON, рендер mono-шрифтом. Индексы `₁` из генератора — сверить глиф-покрытие JetBrains Mono при подключении шрифтов; при tofu — генератор переключить на ASCII `z1/W1` + `<sub>` в UI (план Б из RQ5 §5.5).
- Числа — d3-format 3.1.2, обёртка `src/format/numbers.ts`:
  - ключевое число: `.4g` → `0.6384`, `−0.4231` (≤9 символов с минусом);
  - `|x| < 1e-3`: `.3e` → `−2.451e-5`;
  - drill-down: exact-значение полным repr из JSON + отформатированное значение рядом;
  - display-минус `−` U+2212 (в JSON/данных остаётся ASCII `-`); десятичный разделитель — точка, никогда запятая (Pitfall 13);
  - `tabular-nums` на всех числовых элементах.
- Глоссарий-шпаргалка (Pitfall 13): «∂L/∂W — градиент L по W (в CS231n: dL/dW)», линкуется от любого места с `∂`.

## Color

Основа — Okabe-Ito (colorblind-safe, D-06); нейтрали — Tailwind gray.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | фон страницы и SVG-канвы |
| Secondary (30%) | `#F9FAFB`, рамки `#E5E7EB` | StepPanel, NumberDrilldown, нарратив-строка, контролс-бар, header |
| Accent (10%) | `#E69F00` (Okabe-Ito Orange) | см. reserved-for ниже |
| Destructive | — | деструктивных действий в фазе нет |

**Accent reserved for** (исчерпывающий список — никогда «все интерактивные элементы»):
1. фон-тинт числа, изменившегося на текущем шаге (`step.changed`): `#E69F00` @ 20% alpha, текст остаётся gray-900;
2. активная op на SVG-диаграмме: обводка узла/рёбер `#E69F00`, stroke 3px, fill 10%;
3. primary CTA «Шаг»: рамка 2px `#E69F00`, фон белый, текст gray-900.

Семантические токены (поверх 60/30/10):

| Token | Fill/SVG (чистый Okabe-Ito) | Text (AA на белом) | Использование |
|-------|------------------------------|--------------------|----------------|
| neg — отрицательные значения/градиенты | `#D55E00` Vermillion | `#C24A00` (A-4) | цвет рёбер SVG по знаку веса; цвет текста отрицательных чисел |
| pos — положительные значения/градиенты | `#009E73` Bluish Green | `#007A56` (A-4) | то же для положительных |
| phase-fwd | `#0072B2` Blue | бейдж: точка цвета + текст gray-900 на тинте 12% (A-5) | бейдж фазы forward |
| phase-loss | `#E69F00` Orange | аналогично | бейдж loss (hue совпадает с accent — принято: в Okabe-Ito 8 цветов, различие контекстом и формой бейджа) |
| phase-bwd | `#CC79A7` Reddish Purple | аналогично | бейдж backward |
| phase-upd | `#56B4E9` Sky Blue | аналогично | бейдж update |
| phase-summary | `#6B7280` gray-500 | gray-900 на тинте gray-100 | бейдж «сводка» (шаг 14) |
| neutral-text | — | `#111827` gray-900 / `#6B7280` gray-500 | основной текст / приглушение неизменившихся чисел |

Правила:
- Знак никогда не кодируется только цветом: явный минус U+2212 всегда + цвет (Pitfall 6).
- Yellow `#F0E442` запрещён как текст или фон текста (контраст ≈1.6–1.9:1); в прототипе не используется вовсе.
- Все текстовые пары цвет-на-фоне — WCAG AA (4.5:1 body / 3:1 large): расчёт зафиксировать в `01-DESIGN-TOKENS.md` (чек-пункт; закрывает A1/A8 из Assumptions RESEARCH).
- Метод highlight против «стены цифр»: изменившееся — gray-900 + accent-тинт; неизменившееся — gray-500.

## Interaction Contract

**Layout (один экран, ≥1024px, A-6):**
- Header (min-height 56px): заголовок слева; справа — «Шаг N из 14», бейдж фазы, toggle «Лекционный режим».
- Main: 2 колонки — SVG-диаграмма 55% / StepPanel 45%, gap 32px (xl).
- Bottom bar (min-height 72px): контролы «К началу» «Назад» «Шаг» слева; NarrativeLine справа.
- Слоты фиксированы: смена шага не меняет высоты зон (проекторная стабильность).

**SVG-диаграмма 2-3-1:**
- Слои слева-направо: `x` (2 узла) → скрытый слой (3 узла) → `ŷ` (1 узел); рёбра = веса: W₁ — 6 рёбер, W₂ — 3 ребра; биасы не рисуются (только в StepPanel).
- Ребро: цвет = знак веса (neg/pos fill-токены), толщина 1.5–4px линейно ∝ |w|; числовая подпись ребра скрыта по умолчанию, видна только на активной op и по hover (анти-«стена цифр»).
- Активная op шага: accent-обводка 3px + тинт 10%.
- Layout детерминированный, hand-rolled (топология фиксирована). Клик по узлу/ребру/числу → drill-down этого числа.

**StepPanel — дефолтный вид шага (3–7 ключевых чисел, Pitfall 5):**
- Формула шага с inline-подстановкой чисел (число стоит на месте переменной — связь «формула ↔ число», UX-таблица PITFALLS); клик по числу → drill-down.
- Входы/выходы/градиенты текущей op; изменившееся — accent-тинт, неизменившееся — gray-500.
- Жёсткие потолки: ≤7 ключевых чисел в дефолтном виде; ≤30 чисел на всём экране — красный флаг до теста (self-check скриншотом каждого шага).

**NumberDrilldown:**
- Открывается в слоте StepPanel (замещает содержимое); «← к шагу» возвращает.
- Состав: exact-repr + отформатированное значение + формула + provenance; на backward-шагах — раскрытие цепного правила на 1 уровень.
- Закрытие: backlink, Esc, автосброс при смене шага.

**Клавиатура (UX-01/UX-02 preview):** `→` / `Space` / `PgDn` → next; `←` / `PgUp` → prev; `Esc` → закрыть drill. Видимый focus-ring 2px `#0072B2`, offset 2px на всех интерактивных элементах.

**URL-state (микропроверка DOCS-05):** hash `#step=N&mode=lecture`; запись через `history.replaceState` (без засорения истории); reload восстанавливает состояние; невалидные значения — clamp/дефолт.

**Смена шага:** мгновенная, без анимаций и транзишнов (A-8).

**Лекционный режим:** класс `.lecture` на корне; меняет только CSS-переменные (`--num-size` 16→32, `--ui-size` 16→20), толщину рёбер ×2, `--diag-scale` 1.25. Литмус-тест: скриншот шага → просмотр с 4–5 м (чек-пункт фазы; пост-вопрос юзабилити «видно с задних рядов?»).

- Контролы bottom bar: **[Сброс] [Шаг →] [Запустить эпоху ⏩]**; «Назад» и «К началу» удаляются; клавиатура — только `→` / `Space` / `PgDn` (prev-обработчики удалить)

- Мок-трейс `xor-trace.json` и генератор удаляются: данные ходока теперь считает движок (`src/tensor/`), стартовые веса — константы конфига сценария

## История обучения (R3)

- График лосса: линия по шагам текущей эпохи + точки/сводка по завершённым эпохам; подписи — отформатированные числа (`numbers.ts`), не сырые float
- Таблица весов: строки = веса (W₁[0,0]…b₂), столбцы = эпохи (эпоха 0 = стартовые); обновление в момент завершения эпохи; tabular-nums
- Расположение: под main-областью или правая колонка — зафиксировать при планировании 1.1 (потолок ≤30 чисел на экране пересчитать: история — отдельная зона, не StepPanel)
- История по выделенному блоку/операции — бэклог, не в 1.1

## Анимации (R5 — ревизия A-8)

- **A-8 (rev):** состояние и числа меняются мгновенно; анимация — чистый презентационный слой поверх нового состояния, никогда не задерживает данные и не является источником истины
- Поток forward/backward: «бегущий пунктир» `stroke-dashoffset` с направлением по фазе шага (`data-flow="forward|backward"` на svg + один CSS-селектор), CSS-only ~50 строк; работает и в fast-forward («Запустить эпоху» — поток бежит, панель шага не мелькает)
- Подсветка активной op — CSS-transitions (accent-обводка уже в контракте); WAAPI — точечные one-shot-эффекты, cancel-on-cleanup
- Гейты: `prefers-reduced-motion: reduce` останавливает пунктир/переходы; `.lecture` НЕ выключает анимации (поток — дидактика); `@media print` останавливает пунктир
- e2e: `page.emulateMedia({ reducedMotion: 'reduce' })` в beforeEach скриншот-тестов

## Тултипы (R5)

- `@floating-ui/react` (~10–15 KB gz, первая runtime-зависимость поверх d3-format): ховер/фокус на число или ребро → значение + формула с подстановкой + градиент/знак; a11y — useFocus/useDismiss/ария-описания (UX-04)
- Контент тултипа = лёгкий tier drill-down: данные из `resolveRef`; полный разбор по-прежнему по клику в NumberDrilldown (тултип не заменяет, а анонсирует)
- Мобильный тап: first-tap = hover-эквивалент (тултип), second-tap = drill-down — при планировании 1.1 учесть в протоколе H3
