## User Story (MVP)

**Как** респондент юзабилити-теста, **я хочу** открыть прототип по ссылке и нажатием одной кнопки «Шаг» перейти к следующему шагу XOR-walkthrough с настоящими (сгенерированными эталонным прогоном) числами, **чтобы** риск H3 (понятность пошагового walkthrough) проверялся на живом UI целевого стека, а не на макете.

<objective>
Walking Skeleton фазы: тончайший end-to-end срез — Python-генератор мок-трейса (D-03) → закоммиченный JSON → Zustand-плеер над (trace, stepIndex) → минимальный экран с кнопкой «Шаг» → зелёная production-сборка. Это первый срез реального UI-плеера на целевом стеке (D-01), который Phase 2 дорастит до полного walkthrough, заменяя источник чисел, а не переписывая UI.

Purpose: доказать архитектуру deterministic-replay (ARCHITECTURE.md Pattern 1) до полного UI (планы 01-02–01-03) и до юзабилити-теста; зафиксировать каркас в SKELETON.md.
Output: работающий skeleton-прототип, генератор, валидный трейс, SKELETON.md.
</objective>
