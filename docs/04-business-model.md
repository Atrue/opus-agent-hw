**Дата**: 2026-11-02
**Стадия**: идея
**Автор**: Anton Trusov
**Статус**: черновик для ДЗ; утверждения о рынке и готовности платить — гипотезы, помечены (H)
**Методика**: Business Model Canvas (Osterwalder / Strategyzer), 9 блоков + проверка согласованности и экономической жизнеспособности. Входные данные — `01-product-strategy.md`, `02-value-proposition.md`, `03-market-scan.md`. Известные ограничения BMC (нет метрик, видения, защитимости) закрыты doc 01; здесь — операционная целостность: как блоки усиливают друг друга.

---

## TL;DR

Канвас описывает **бизнес-модель влияния, а не выручки**: себестоимость ≈ 0 (статик-сайт, вычисления в браузере клиента), цена = бесплатно, CAC ≈ 0 (PLG/SEO), поэтому модель устойчива без дохода — но и денежный тест LTV > 3×CAC сегодня неприменим (LTV = 0 by design). Центральный узел модели — **преподаватель**: он и канал (B2B2C), и удержание (эмбеды в LMS = switching costs), и единственный правдоподобный будущий покупатель (B2B-интеграции для вузов/буткемпов, гейт после R2). Студенты не платят никогда — это осознанный трейдофф из стратегии (п. 5), а не недоработка. Главный ресурс и главный риск канваса совпадают: время одного автора.

## 1. Customer Segments (Сегменты)

Из `01-product-strategy.md` (п. 2), тип рынка: **нишевый с двусторонней динамикой (B2B2C)** — преподаватель приводит студентов пачками каждый семестр.

| Сегмент | Роль в модели | Характеристики |
|---|---|---|
| Студенты 1-го курса DL (P1) | основной получатель ценности, **не платит никогда** | семестровые волны; боль острейшая (backprop — фильтр); switching cost ≈ 0; приходят через преподавателя или поиск |
| Преподаватели (P2) | канал дистрибуции + якорь удержания + будущий B2B-покупатель | gatekeepers (Porter); мало времени; ожидают бесплатности; повторное использование каждый семестр |
| Самоучки/свитчеры (P3) | дополнительный приток, активация после R2 | ценность в v1 частичная (нет своих сетей/данных до конструктора) |

Явно НЕ сегменты: исследователи, продакшн ML-инженеры, kaggle-игроки, ищущие «курс по ML целиком».

## 2. Value Propositions (Ценностные предложения)

Ядро (из `02-value-proposition.md`): единственное место, где **пошаговое исполнение backward + каждое промежуточное число + визуализация графа + нулевой порог входа** совмещены.

| Сегмент | Ценность | Тип |
|---|---|---|
| Студент | понять механику на числах, а не зазубрить формулы; «ага-момент» на первом шаге | качественная (понимание vs вера) + количественная: первый шаг < 1 мин, шаг < 100 мс (цели) |
| Преподаватель | живое демо без подготовки; один сценарий — каждый семестр | качественная (внимание аудитории) + количественная: часы подготовки → 0 |
| Самоучка | интуиция диагностики вместо слепого перебора (частично до R2) | качественная |

Позиционирование против субститутов: «бот — учебник, тренажёр — спортзал» (практика vs объяснение, из market scan).

| Фаза | Канал | Тип |
|---|---|---|
| Осведомлённость | SEO: интерактивные статьи под «backprop пошагово» (O4: конкуренция низкая, H) | owned, прямой |
| Осведомлённость | Преподаватели → встраивание в курс (B2B2C; 1 курс = семестровый поток) | partner, косвенный |

| После использования | Open-source репозиторий, GitHub issues; классической поддержки нет | owned |

## 4. Customer Relationships (Взаимоотношения)

- **Студент**: автоматизированный self-service, без регистрации, разовая сессия. CAC ≈ 0, удержание от природы низкое (W4) — рост через приток, не через retention (стратегия, риск 2).
- **Преподаватель**: персональная помощь на этапе пилота (интервью, онбординг сценария — H2), дальше автоматизированное переиспользование; switching costs растут после эмбеда в LMS — осознанный механизм удержания.
- **R2+**: co-creation — открытые пользовательские сценарии, сообщество контрибьюторов (петля усиления из стратегии, п. 7).

## 5. Key Activities (Ключевые активности)

| Активность | Зачем | Период |
|---|---|---|
| Методический контент: сценарии XOR → спираль → MNIST с нарративом | это одновременно продукт и ров (невозобновляемый актив) | R1 |
| Мини-autodiff движок (reverse-mode) с трассировкой шага | техническое ядро; копируемо, поэтому не ров | R1 |
| Визуализация графа с drill-down (диаграмма → слой → операция → число) | снятие риска «стены цифр» (стратегия, риск 3) | R1 |
| Валидация: интервью преподавателей (H2), юзабилити (H3), A/B понимания (H1) | до кода — главные точки отказа | R1 |
| Дистрибуция: SEO-статья, пилотные курсы, комьюнити-посты | двойное использование контента | R1–R2 |
| Автотесты чисел против эталонной реализации | guardrail корректности | постоянно |
| Конструктор сетей + CSV + эмбеды LMS | закрытие W5 и субститут-риска | R2 |

## 6. Key Resources (Ключевые ресурсы)

| Ресурс | Тип | Копируемость |
|---|---|---|
| Автор (время, методика, код) | человеческий | — ; key person risk (W2) |
| Библиотека сценариев с выверенной дидактикой | интеллектуальный | **низкая — единственный настоящий ров** |
| SEO-активы и обратные ссылки | интеллектуальный | низкая (копятся медленно) |
| Код движка и визуализации | интеллектуальный | высокая (T3) — честно: не защита |
| Open-source стек, статик-хостинг, готовая аналитика (Buy) | технический | коммодитизировано |
| Бюджет | финансовый | ≈ 0; основная инвестиция — время автора |

Минимальный жизнеспособный набор: один автор + open-source стек + статик-хостинг + один эталонный сценарий до конца.

## 7. Key Partners (Ключевые партнёры)

- **Преподаватели пилотных курсов (5–10)** — партнёры по дистрибуции, не поставщики; дают аудиторию для методических итераций (закрывает W3).
- **Open-source экосистема** — viz-библиотеки (SVG/Canvas), autodiff-референсы (micrograd и аналоги); лицензии MIT/Apache, конфликтов нет (PESTLE L).
- **Инфраструктура**: статик-хостинг, аналитика — мгновенная замена, силы поставщиков низкие (Porter), некритичны.
- **R2+ (всё H)**: вузы/буткемпы/корпоративное обучение — потенциальные B2B-партнёры и первые покупатели; грантовые программы ИИ-грамотности (P-фактор PESTLE) как «партнёр-спонсор».

## 8. Cost Structure (Структура издержек)

- **Характер**: cost-driven по структуре при value-driven предложении — дидактика качества почти ничего не стоит в деньгах, только во времени.
- **Fixed**: время автора (доминирующая статья, opportunity cost), домен, обслуживание репозитория.
- **Variable**: ≈ 0 на пользователя — вычисления в браузере клиента (E-фактор PESTLE), статик-хостинг, freemium-аналитика.
- **Cost drivers**: методическое качество контента и итерации со студентами; НЕ инфраструктура и НЕ масштаб.
- Следствие: рост числа пользователей с 10 до 10 000 не меняет издержки — модель не ломается при вирусном росте.

## 9. Revenue Streams (Потоки выручки)

| Поток | Статус | Механизм ценообразования |
|---|---|---|
| R1: нет выручки | **осознанно** (трейдофф «бесплатное ядро без регистрации», стратегия п. 5; сегмент приучен к бесплатности — T5, E-PESTLE) | — |
| B2B-лицензии: вузы, буткемпы, корпоративный онбординг джунов | гейт после R2 (H) | value-based: платят за интеграцию, LMS-эмбеды, поддержку/SLA — не за виджет (market scan, рек. 5) |
| Гранты ИИ-грамотности (RU нацпроекты) | возможно, R1–R2 (H) | заявочная |
| Платные «лабораторные пакеты» с проверкой заданий | опция R2+ (H) | per-course |

Кто не платит никогда: студенты (P1) — принципиально; это условие дистрибуции через преподавателей, а не упущенная выручка.

## Согласованность блоков (alignment check)

1. **Бесплатность ↔ нулевая себестоимость ↔ PLG ↔ SEO**: цена 0 возможна потому, что издержки 0; издержки 0 возможно потому, что вычисления на клиенте; всё это делает «ссылка = продукт» честным.
2. **Преподаватель — узловая роль в 4 блоках**: сегмент (P2) + канал (B2B2C) + удержание (LMS switching costs) + будущая выручка (B2B). Если H2 не подтвердится, разваливается не один блок, а связка четырёх — поэтому интервью до кода.
3. **Сценарная библиотека — двойное использование**: ключевая активность (создаётся) = ключевой ресурс (ров) = контент для SEO-канала = ценность для преподавателя. Одна работа закрывает четыре блока.
4. **Осознанный разрыв**: блок «выручка» не связан с P1-сегментом. Это не ошибка канваса, а модель влияния (market scan: «цель года — влияние и дистрибуция»); проверка денежной модели вынесена в гейт после R2.

## Экономическая жизнеспособность (LTV > 3×CAC)

- **В деньгах сегодня**: LTV = 0 (нет монетизации by design), CAC ≈ 0 (PLG/SEO) → классический тест **неприменим**; делить ноль на ноль — не анализ.
- **Proxy-метрика вместо денег**: стоимость завершённого walkthrough = (время автора) / (число completions, North Star из стратегии). Цель — чтобы proxy падала с каждым семестровым циклом за счёт переиспользования сценариев.
- **Будущая денежная валидность**: появляется только с B2B-потоком; там LTV строится на семестровом цикле переиспользования (retention преподавателя), CAC — на личных пилотах (низкий). При цене годовой лицензии ≥ 3× стоимости интеграции и поддержки модель сходится (H, проверить интервью).
- **Честный вывод**: как бизнес viability не доказана и сейчас не проверяется; как проект влияния с нулевой себестоимостью — устойчив неограниченно долго при энтузиазме автора. Долгосрочный риск № 1 модели — не конкуренты, а выгорание/дефицит времени автора (T6 + W2).

## Вывод

Канвас целостен как **модель влияния с встроенной опцией на будущую B2B-монетизацию**: все блоки R1 согласованы вокруг нулевой себестоимости и дистрибуции через преподавателей; денежные блоки — загружены минимально и осознанно. Решение о переходе к бизнес-модели с выручкой — отдельный гейт после R2 (H5/H6), не раньше. Следующий шаг не меняется: H2/H3 до кода.
