# Backprop Trainer — интерактивный тренажёр обучения нейросетей

Бесплатный браузерный тренажёр, в котором студент **сам пошагово исполняет** forward- и backward-pass готовой нейросети (MLP: XOR → спираль → MNIST) и видит каждую операцию числами: входы, выходы, активации, градиенты — от диаграммы архитектуры до drill-down любого отдельного числа.

**Позиционирование:** «backprop без магии — на числах, в браузере, за один клик».

## Продукт и цели

- **Core Value:** пользователь сам исполняет каждый шаг и видит каждый градиент числом — при нулевом пороге входа (браузер, без регистрации, ссылка = продукт, первый шаг < 1 мин).
- **North Star:** число пользователей в неделю, завершивших полный walkthrough хотя бы одного сценария.
- **MVP R1 (D-18):** DOCS-01 + DOCS-02 на сценарии XOR. H2/H3 (готовность преподавателей + юзабилити) валидируются до основного кода.
- **Аудитория:** студенты первых курсов DL (P1), преподаватели ML (P2).

## Ограничения (Definition of Done guardrails)

- **NFR-01 (перфоманс):** один шаг любого сценария, включая MNIST, < 100 мс на среднем ноутбуке без GPU.
- **NFR-02 (корректность):** 100% операций движка покрыты юнит-тестами с фиксированными эталонными константами; относительное отклонение ≤ 1e-6; CI-инварианты «drill-down = движок», «пошагово = fast-forward». Опечатка в градиенте убивает доверие к продукту.
- **NFR-03 ($0-архитектура):** всё в браузере, статик-хостинг, серверных вычислений нет; 100% сессий без регистрации; аналитика анонимная (152-ФЗ/GDPR).
- **Прогон forward-only:** «шаг назад» отсутствует by design (как в реальном обучении); URL несёт только сценарий, reload = честный сброс.
- **Ресурсы:** один автор; новые пакеты/библиотеки — только через явные чекпойнты (см. `AGENTS.md`).

## Стек

TypeScript (strict) · React 19 · Vite 8 · Tailwind 4 · собственный float64-движок reverse-mode autodiff (`src/tensor/`, порт семантики micrograd) + живой прогон (`src/run/`) · Zustand не используется (useSyncExternalStore) · Vitest 5 + Playwright · pnpm.

## Архитектура (кратко)

- `src/tensor/` — тензорная библиотека op-уровня (Tensor, ops, ленивые экспандеры drill-down); публичный вход — только `index.ts`.
- `src/run/` — живой forward-only прогон: `TrainingRun`, курсор `SampleCursor`, эпохи, fast-forward, история.
- `src/ui/` — React-слой: диаграмма архитектуры (SVG), панель операции, drill-down, график лосса, таблица весов.
- UI пересчитывает шаги движком, а не проигрывает предвычисленный трейс.
