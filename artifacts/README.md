# artifacts/ — постоянное хранилище артефактов проекта

Отличается от `.planning/ui-reviews/` (рабочие captures ревью/UAT, не коммитятся,
чистятся при закрытии milestone): здесь — **коммитящаяся история**, произвольные
форматы, живёт вечно.

## Конвенция

- Имя файла: `YYYYMMDD-NNN-<slug>.<anyformat>` — дата + трёхзначный порядковый
  номер внутри этой даты (`001`, `002`, …) + короткое имя через дефис, kebab-case.
  Новый файл получает номер, следующий за последним использованным в этот день
  (`ls artifacts/ | grep ^YYYYMMDD`), — файлы одного дня идут по порядку.
  Пример: `20261105-003-redesign-dark-ui.png`.
- Структура произвольная: скрины «как было / как стало», референсы, дампы,
  экспорты; пары «было/стало» различай суффиксами (`-before` / `-after`).
- Каждый файл описывается строкой в инвентаре ниже — что это, откуда, контекст.
- Тяжёлое (видео, дампы > ~1 МБ) не коммитим — кладём рядом ссылку на источник.
- Содержимое не мутируем: правки/замены — новым номером (история в git).
