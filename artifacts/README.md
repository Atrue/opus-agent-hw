# artifacts/ — постоянное хранилище артефактов проекта

Отличается от `.planning/ui-reviews/` (рабочие captures ревью/UAT, не коммитятся,
чистятся при закрытии milestone): здесь — **коммитящаяся история**, произвольные
форматы, живёт вечно.

## Конвенция

- Имя файла: `YYYYMMDD-<slug>.<anyformat>` — дата + короткое имя через дефис,
  kebab-case. Пример: `20261105-first-ui.png`.
- Структура произвольная: скрины «как было / как стало», референсы, дампы,
  экспорты — всё в одну папку с датой в имени; при желании пары «было/стало»
  различай суффиксами (`-before` / `-after`).
- Каждый файл описывается строкой в инвентаре ниже — что это, откуда, контекст.
- Тяжёлое (видео, дампы > ~1 МБ) не коммитим — кладём рядом ссылку на источник.
