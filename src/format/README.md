# src/format — форматирование чисел

Единственное место форматирования чисел для UI (UI-SPEC «Notation & Number
Format»): `d3-format` 3.1.2 — значащие цифры (`.4g`), экспонента для малых
градиентов (`.3e`), типографский display-минус U+2212.

- `numbers.ts` — форматтеры чисел (1 модуль, без собственного состояния);
- `numbers.test.ts` — тесты рядом (D-28а).

Числа не вычисляются здесь — приходят значения снапшотов движка; строки
формул drill-down строятся из чисел сценария.
