# src/format — форматирование чисел

Единственное место форматирования чисел для UI (UI-SPEC «Notation & Number
Format»): `d3-format` 3.1.2 — значащие цифры (`.4g`), экспонента для малых
градиентов (`.3e`), типографский display-минус U+2212. Публичный вход —
баррел `index.ts` (D-34: потребители импортируют `../format`).

- `minus.ts` — display-минус U+2212 + конверсия ASCII-минусов;
- `formatKey.ts` — ключевое число `.4g` / `.3e`;
- `exactRepr.ts` — полный repr для drill-down;
- `index.ts` — баррел публичной поверхности;
- `numbers.test.ts` — тесты рядом (D-28а), тестирует баррел.

Числа не вычисляются здесь — приходят значения снапшотов движка; строки
формул drill-down строятся из чисел сценария.
