# DECISIONS.md

> Журнал принятых решений. Дата — когда решение зафиксировано в документах. «Почему» — краткая причина; отброшенные альтернативы — чтобы агент не предлагал их снова.

## Продукт и позиционирование

### D-01. Позиционирование: «backprop без магии — на числах, в браузере, за один клик»
- **Когда**: 2026-11-02 (docs/01, п.1)
- **Почему**: убирает главный страх входа в DL; обещание совпадает с продуктом.
- **Отброшено**: «лучший способ выучить deep learning» (мы тренажёр, не курс — обещание шире продукта); «TF Playground, но с backward-pass» (определяться через чужой продукт — слабая рамка).

### D-02. v1 — только готовые сценарии; конструктор сетей + CSV отложены в R2
- **Когда**: 2026-11-02 (docs/01, п.5; docs/02, сегмент 3)
- **Почему**: порог входа и время до «ага-момента» решают всё; конструктор — для тех, кто уже понял базу. Следствие: ценность для P3 (свитчеров) в v1 частичная — осознанно.

### D-03. Пошаговость и наглядность вместо производительности; MNIST — потолок v1
- **Когда**: 2026-11-02 (docs/01, п.5)
- **Почему**: принцип «обучаемость > скорость»; браузер, ноль установки, вычисления на клиенте — себестоимость ≈ 0.

### D-04. Глубина вместо широты: только механика обучения (forward/backward)
- **Когда**: 2026-11-02 (docs/01, п.5)
- **Почему**: одна боль, решённая отлично, лучше десяти решённых наполовину. Все архитектуры/RL/трансформеры — не наш сегмент.

### D-05. Нулевой порог: браузер, без установки, без регистрации; ссылка = продукт
- **Когда**: 2026-11-02 (docs/01, п.5, п.6)
- **Почему**: мгновенный доступ из любой аудитории, шеринк, эмбеды; цель — первый выполненный шаг < 1 мин; доля сессий без регистрации = 100% по дизайну.

## Стратегия и рынок

### D-06. Не конкурировать с LLM-ассистентами за «объяснение» — занять «практику»
- **Когда**: 2026-11-02 (docs/03, TL;DR, синтез сигнал 2)
- **Почему**: LLM — главный субститут 2026 (объясняют backprop по запросу) и одновременно драйвер спроса на понимание. «Бот — учебник, тренажёр — спортзал» — разные JTBD. Ответ на субститут-риск — измеримый прирост понимания (H1), не война за объяснения.

### D-07. Преподаватели — узловая роль модели (B2B2C), валидировать H2 до кода
- **Когда**: 2026-11-02 (docs/03, рек. 1; docs/04, alignment check п.2)
- **Почему**: преподаватель — одновременно канал, удержание (LMS switching costs) и будущий B2B-покупатель; связка 4 блоков BMC развалится, если H2 не подтвердится.

### D-08. Цель 12 месяцев — влияние и дистрибуция, не выручка
- **Когда**: 2026-11-02 (docs/03, TL;DR; docs/04)
- **Почему**: денег в сегменте нет ни у кого (все альтернативы бесплатны, T5); модель устойчива при себестоимости ≈ 0. Монетизация — опцион за гейтом после R2-метрик (H5/H6).

### D-09. Ров строится контентом, методикой и дистрибуцией — не технологией
- **Когда**: 2026-11-02 (docs/03, сигнал 1; docs/04, ключевые ресурсы)
- **Почему**: барьеры входа ≈ 0 (Porter), код движка копируем за недели (T3). Невозобновляемые активы: библиотека сценариев с выверенной дидактикой, SEO-позиция, эмбеды в LMS. Копировать код легко — методику нет.

### D-10. RU-рынок как плацдарм, потом EN-масштаб
- **Когда**: 2026-11-02 (docs/03, O6; Ansoff)
- **Почему**: Habr/вузы, меньше конкуренции за внимание; источник первых пилотов (H).

### D-11. Последовательность роста: проникновение → развитие продукта (R2) → развитие рынка; диверсификация — не раньше подтверждения R2
- **Когда**: 2026-11-02 (docs/03, Ansoff)
- **Почему**: не распылять ресурс одного автора.

## Монетизация и прайс

### D-12. Студенты (P1) и преподаватели лично (P2) не платят никогда; цена контента = 0 навсегда
- **Когда**: 2026-11-02 (docs/05, п.1)
- **Почему**: сегмент приучен к бесплатности (T5); платный доступ убил бы дистрибуцию через преподавателей. Это условие модели, не упущенная выручка.

### D-13. Модель: freemium-ядро + value-based tiered B2B; активация — гейт после R2-метрик
- **Когда**: 2026-11-02 (docs/05, п.2, п.7)
- **Почему**: бесплатное ядро кормит дистрибуцию; платят вузы/буткемпы/корпорации.
- **Отброшено**: flat-rate (ценность различается на порядок); per-seat (taxing heads противоречит бесплатности P1); usage-based (себестоимость ≈ 0 — цена наказывала бы рост).

### D-14. Value metric — «активный курс» (семестровое преподавание); верхняя форма — годовая site-лицензия
- **Когда**: 2026-11-02 (docs/05, п.2)
- **Почему**: синхронна циклу ценности (семестровые волны), проверяема через LMS-эмбед, предсказуема для бюджета кафедры.
- **Отброшено**: число студентов (friction, противоречит D-12); число сценариев (наказывает глубину главного рва).

### D-15. Правило гейтинга: платное = интеграция/управление/поддержка (LTI, SSO, аналитика, проверка заданий, SLA); бесплатное = сам контент и понимание
- **Когда**: 2026-11-02 (docs/05, п.4)
- **Почему**: тест одной строкой — фича увеличивает North Star (completions) → бесплатная; снижает стоимость/риск для организации → платная. Публикация прайса — не раньше ≥ 1 LOI.

### D-16. Закрытые двери: реклама, продажа данных студентов, B2C-подписка
- **Когда**: 2026-11-02 (docs/05, п.2)
- **Почему**: реклама разрушает доверие образовательного продукта; данные — 152-ФЗ/GDPR; B2C — T5 навсегда.
