# DESIGN.md — «Backprop без магии» (рабочее: XOR — backprop за 14 шагов)

## 1. Atmosphere

**Точный. Лабораторный. Спокойный.** Тёмная панель измерительного прибора: экран осциллографа, на котором нейросеть «живёт» числами, а не картинкой-иллюстрацией.

- **Плотность**: высокая, но ранжированная — «стена цифр» запрещена стратегией (риск из docs/01); плотность оправдана прогрессивной детализацией: диаграмма → слой → операция → число.
- **Вариативность**: жёсткий каркас-скаффолд (рельс шагов + сцена DAG + колонка результата/операции + статус-бар, транспорт в шапке), внутри — живые данные сценария; варьируются числа и подсветки, не структура.
- **Моушн**: только функциональный — пульс текущего шага, «градиентная волна» по рёбрам DAG, ping живого статуса. Движение = смысл (поток вычислений), не украшение.

### 2.1. Знак числа (Okabe-Ito, роль вне палитры 60-30-10)

Знак числового значения — отдельная роль, не входящая в акцентные 10 %: colorblind-safe пара Okabe-Ito (Pitfall 6: знак никогда не кодируется только цветом — минус U+2212 всегда присутствует глифом).

| Токен             | Hex       | Роль                                                    |
| ----------------- | --------- | ------------------------------------------------------- |
| `neg`             | `#D55E00` | Vermillion — отрицательные значения/градиенты: SVG-заливки, рёбра DAG |
| `pos`             | `#009E73` | Bluish Green — положительные: SVG-заливки, точки         |
| `neg-text`        | `#FF8A50` | текст отрицательных чисел на тёмных поверхностях        |
| `pos-text`        | `#00C489` | текст положительных чисел на тёмных поверхностях        |

Чистые `neg`/`pos` — нетекстовые (≥3:1 на всех поверхностях, WCAG 1.4.11; фактически ≥4.2:1); светлые `*-text` — текстовые AA-варианты (≥4.5:1). Различимость `pos-text` `#00C489` против `primary` `#4edea3` — по контексту (числа в панелях vs UI-акценты), hue-разница сохранена.

Шкала: `label-sm` 12 px (лейблы, бейджи) · `body-sm` 14 px (пояснения) · `label-md` ~14 px mono · `headline-sm` ~18 px (заголовки карточек) · `headline-md` ~20–24 px (заголовок секции chain rule). Межстрочный: body 1.5, заголовки 1.2–1.3, код/формулы `leading-tight` ≈ 1.25. Лейблы — sentence case, без трекинга, на шаг мельче body (крупные капс-надписи запрещены: читаемость чисел — главный контент).

## 4. Spacing & Grid

- **База 8 px**, полушаг 4 px (`space-xs`); токены: `space-sm` 8 · `space-md` 16 · `gutter-desktop` 20 · `margin-mobile` 12.
- **Радиусы**: 2 / 4 / 8 / 12 px (`DEFAULT/lg/xl/full`) — нарочито мелкие, «приборные». Никаких «пузырей».
- **Макет**: 12-колоночная сетка (брейкпоинт `xl`): рельс шагов 2 (вертикальный, «стек отладчика») | сцена 6 (DAG крупно + история полосой: график лосса и таблица весов) | правая колонка 4 (зона результата + панель операции); `md` — 2 колонки, mobile — одна (рельс складывается в горизонтальную ленту).
- **Рельс шагов**: 2 → 4 колонки по брейкпоинтам ниже `xl`, на `xl` — 1 колонка (вертикаль).
- **Хром**: шапка-транспорт — заголовок, бейдж фазы, контролы прогона (primary «Шаг» всегда в зоне досягаемости), «Лекционный режим»; фиксированный футер-статус-бар высотой 48 px (LOSS / LR + индикатор позиции + hotkeys).

## 5. Components

- **Кнопка primary**: `bg-primary-container` `#10b981`, текст `#00422b`, `label-sm` weight 600 (sentence case), radius 4, единственная заливка на экране; hover → `bg-primary`; active → темнее; focus → `ring-1 primary`. Quiet (Сброс, Запустить эпоху): прозрачный фон + hairline-бордер `outline-variant`, hover `container-high`. Disabled: `opacity-60`.
- **Кнопка-паттерн** (`[0,1]`…): моно, compact `py-1`; активная — primary-container, неактивные — container-high + `transition-colors`.
- **Карточка**: `bg-surface-container-low`, паддинг 16, radius 2, `shadow-sm`, внутренний `gap` 8; шапка = иконка + `headline-sm` + правый мета-бейдж.
- **Инпут**: `bg-surface-container-lowest`, mono, `focus:ring-1 primary`; валидация цветом текста фидбека (primary/error), не рамками-«електричками».
- **Степпер-пилюля**: 3 состояния — пройденное (`opacity-80`, значения заполнены), **активное** (`surface-container-high` + `ring-1 primary` + оверлей `primary/10 animate-pulse`), будущее (`opacity-60`).
- **Ячейка матрицы**: `bg-surface-container` → hover `container-high`; выбранная — `ring-1 primary` + значение primary. Внутри: лейбл, значение mono, Δw.
- Сегмент-табы, range-слайдер (`h-1`, `accent-secondary`), код-блок (`pre` на container-lowest), бейдж фазы, callout-заметка с иконкой, `kbd`.
- **Зона результата** (правая колонка): ŷ, y, L крупным моно (×1.25 от `--num-size`) + вердикт порогом 0.5 («✓ Верно» primary / «Не сошлось» error); до первого вычисления — «н/д»; тренд L (↓/↑) против предыдущей лосс-точки — нейтральный глиф.

## 6. States

| Состояние   | Как выглядит                                                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Empty**   | сценарий не начат: рельс серый (`outline`), значения «н/д»/пустые слоты пилюль, DAG без подсветок                                    |
| **Loading** | ping-точка secondary + строка «Обратное распространение ошибки по графу вычислений»; числа не мигают — приходят пачкой на шаг                                                         |
| **Partial** | середина walkthrough: шаги 1–6 пройдены, 7 активен (ring + pulse), 8 заблокирован; выход `0.180 (Не сошлось)` в `error`; edge-case озвучен: «нулевой входной сигнал!» при ∂L/∂w₁₁ = 0 |
| **Error**   | неверный ответ квиза → подсказка «перемножьте первые 4 сомножителя» в `text-error` (не блокирует, ведёт к ответу); в футере — детектор затухающего градиента вместо безликого fail    |
| **Success** | квиз: «✓ Верно! ∂L/∂b₁ = …» в primary; футер: `Healthy (No Vanishing)` c пульс-точкой; Loss ↓ 0.041 — успех = число, подсветившееся мятой, без конфетти                               |

## 7. AI UX

LLM-чата в v1 нет (PRODUCT.md: «бот — учебник, тренажёр — спортзал»); паттерны агентного UX применяем к **движку пошагового исполнения**:

- **Стрим**: числа «протекают» по графу — градиентная волна амбер-dash от выхода ко входу; значение появляется тогда, когда вычислено на текущем шаге, не раньше.
- **Шаги агента = шаги движка**: 13-операционный рельс — хребет навигации; текущий шаг всегда виден (ring + pulse + `ТЕКУЩИЙ`). Ограничение проекта (D-21/D-25): прогон forward-only — возврат кликом по пилюле НЕ реализуется, рельс — индикатор (done/active/future + mono-значения), «шаг назад» исключён.
- **Optimistic**: слайдер LR и переключатель паттерна `[0,1]↔[1,0]` обновляют числа и Δw мгновенно, без спиннеров и пересбора экрана.
- **Стоп/контроль**: hotkeys `Space` — шаг, `R` — reset, `B` — к backward; walkthrough двусторонний (любой шаг можно переиграть), автопроход всегда останавливаем.

## 8. Motion

| Ситуация                          | Параметры                                                                 |
| --------------------------------- | ------------------------------------------------------------------------- |
| Hover (кнопки, ячейки, рёбра DAG) | `transition-colors/all` 150 ms, ease-out                                  |
| Активный шаг                      | `pulse` 2 s (оверлей `primary/10`)                                        |
| Живой статус                      | `ping` 1 s, `cubic-bezier(0,0,.2,1)`                                      |
| Градиентная волна по рёбрам       | dash-offset анимация ~1.2 s, linear, loop — кодирует направление backprop |
| Появление значений шага           | fade+rise ≤ 200 ms, ease-out                                              |

`prefers-reduced-motion`: отключаем ping / pulse / dash-анимацию полностью; остаются только цветовые переходы ≤ 150 ms. Движение — всегда носитель смысла (поток вычислений), никогда — фон.

## 10. Don'ts

- **Градиенты как декор** — единственный градиент в системе функционален: кодирует направление потока в SVG-DAG.
- **Эмодзи и эмодзи-карточки** — иконки только Material Symbols; «✓» допустим лишь как глиф проверки ответа.
- **Фиолетово-синяя «AI-стартап» палитра**, неоновое свечение заголовков (glow — только на выбранном узле DAG).
- **Стекломорфизм** — backdrop-blur только у фиксированного футера и floating-легенды, не у контента.
- **Радиусы > 12 px**, «пузыри», 3D-блобы, параллакс.
- **Конфетти/геймификация успеха** — успех = мятная подсветка точного числа.
- **«Стена цифр»** (риск из стратегии): никогда не показываем все числа без иерархии и шага-контекста.
- **Анимация ради анимации**; спиннеры поверх уже вычисленных чисел; блокировка ввода во время пересчёта (нарушает optimistic-принцип).
