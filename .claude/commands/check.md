description: Полная проверка проекта одной командой — build + test + lint
---

Запусти проверку проекта последовательно и доложи результат каждого шага:

1. `npm run build` — production-сборка (единственная проверка синтаксиса в проекте)
2. `npm test` — юнит-тесты Vitest
3. `npm run lint` — ESLint по конфигу проекта
4. `npx eslint src/ --ext .js,.jsx` — страховка явного охвата `.jsx` (находка Discovery про «ложнозелёный lint» при живой проверке 2026-10-23 не воспроизвелась, но явный `--ext` дешевле, чем верить находке на слово)

Правила:

- Если шаг упал — остановись, почини и перезапусти с него; не пропускай шаги.
- Не правь код молча: сначала покажи, что именно упало и почему.
- В конце дай сводку: какой шаг зелёный/красный и итоговое состояние проекта.
